# V7 09:26 竞价速览规格

## 用途和口径

速览是 09:26 的候选观察摘要，不是交易信号。回放数据必须显示“历史回放样本,非当时实时生成的交易信号”。阈值版本固定为 `V1`，展示“V1 冻结工程阈值,非市场规律、未回测”。百分比变化来自竞价价相对昨收；市场和板块均只使用有效价格。

## V1 冻结工程阈值

| 规则 | 阈值与公式 |
| --- | --- |
| 市场覆盖 | 有效价格数/市场股票数 ≥95%；不足时市场和板块均不下结论。 |
| 普遍高开 | 市场上涨占比 ≥70%，且市场开盘变化中位数 ≥+0.50%。 |
| 昨板接力落后 | 昨日涨停池有效价格至少 20 只，且昨板上涨占比−市场上涨占比 ≤−15pp。 |
| 板块合格 | 成员数 ≥5；价格覆盖、竞价金额覆盖各 ≥90%；板块竞价额/全市场有效竞价额 ≥0.5%；板块中位涨幅 ≥+0.50%；板块上涨占比−市场上涨占比 ≥+5pp。金额分母复用市场指标中的有效竞价额。 |
| 主看/备看 | 排除 BROAD 类；成员数 ≥100 的合格板块按 D 降序选主看；成员数 5–99 的合格板块按 D 降序选备看。并列依次按 E 降序、板块竞价额降序、板块代码升序。备看与主看的金额 Top3 重叠达到 2 只时跳过，取下一名。 |
| 弱势风险 | 昨日连板数 ≥2 且竞价涨幅 ≤−3% 时列入最多两只弱势股。昨日≥2板竞价封下一板单独列出确认数/昨日≥2板池数。 |

D 表示板块开盘变化中位数（%）；“超市场”是板块中位数减市场中位数（pp）。E 表示板块上涨占比减市场上涨占比（pp）。竞价额为成员已知金额之和；金额 Top 股票使用全市场 `amount_rank`，并显示名称、名次和金额。金额排序并列按证券代码升序。0.5% 为 V1 冻结工程阈值，非市场规律，未回测；准入和备看排序调试信息均显示占比，流动性门槛排除项记录 `PLATE_AMOUNT_SHARE_BELOW_MIN`。

## 字段与缺失处理

JSON 产品字段为 `schema`, `threshold_version`, `threshold_note`, `thresholds`, `metrics`, `rules`, `lines`。`metrics` 保存市场、昨板池、封单、昨日≥2板计数和板块可审计指标；`rules` 保存覆盖判断、规则命中、逐板块数值、每个未入选板块的拒绝原因、主看/备看及备看重叠淘汰的分数依据。产品写入 `report.json` 顶层 `auction_quickbrief`，并附入 `auction_panorama.quickbrief`。

缺值保持 `null`，不得填零。有效价格缺失不进入价格分母；竞价金额缺失不进入金额覆盖分子，金额覆盖分母仍为板块成员数。未达到覆盖阈值就记录 `PRICE_COVERAGE_BELOW_MIN`、`AMOUNT_COVERAGE_BELOW_MIN` 或市场覆盖不足，不选择板块。股票名称缺失时显示证券代码；金额名次缺失时显示“待核实”。无法判定封板状态时不计为已封下一板，也保留状态未知的分母和覆盖限制。任何公式只作为观察口径，不把缺失解读为零。

## 09:32 开盘验证预案（本卡只记录规格，不实现）

对每个已选板块计算 `D32 = 板块开盘变化中位数 − 市场开盘变化中位数`，以及 `F32 = 09:32 不低于竞价价的成员数 / 有效开盘价格成员数`。另列 Top3 中不低于竞价价的只数；涨停封板保持单列，不并入普通延续比例。

- `D32 ≥ +0.2pp`、`F32 ≥60%` 且 Top3 至少 2 只不低于竞价价：初步延续。
- `D32 ≤−0.2pp` 且 `F32 ≤40%`：验证失败。
- 其他有足够数据的结果：继续观察。
- 市场或板块价格覆盖不足、分母为空或关键字段缺失：无法验证，不补零。

09:32 结果仍是观察性验证，不代表历史策略回测或生产交易结论。

## C303 题材分化与昨日接力口径

以下阈值均为 V1 冻结工程阈值，非市场规律且未回测。共同题材接力样本少于 3 只标“样本不足”；样本达到 3 只后，偏弱条件为题材高开率比市场低至少 15pp，或题材涨幅中位数比市场低至少 1pp；偏强条件为高开率不低于市场且涨幅中位数至少高于市场 1pp；其余为“分歧”。优先级是样本不足、偏弱、偏强、分歧。合并的“其他单只题材”仅汇总家数与竞价额，接力显示“不适用·非共同题材”。

内部分档为涨幅≥+3%、0≤涨幅<+3%、涨幅<0%，零涨幅归中间档。“多数行为”仅当某档严格超过有效样本的 50% 时显示该档名称，否则显示“分散”。个股涨幅距题材中位数至少 3pp 才点名为明显极值；未达则显示“无明显极值”。P75−P25 保留在产品数据中，视图只在达到 4pp 时显示。昨日≥2板高标逐只显示，不按原因组样本数隐藏。阅读顺序固定为速览卡、昨日整批统计/市场整体、题材分化、昨日接力、高标与封单极值；HTML 与文本一致。
